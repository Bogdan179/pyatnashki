# Пятнашки

Классическая игра «Пятнашки» на Python с графическим интерфейсом (tkinter).

## Запуск

```
python main.py
```

Открывается окно с полем 4×4 по умолчанию. Зависимостей нет — только стандартная библиотека Python 3.

## Как играть

Соберите плитки по порядку: 1, 2, 3, … с пустой клеткой в конце. Стартовая раскладка всегда решаемая (проверка методом подсчёта инверсий).

Управление (переключается в меню «Настройки → Управление»):

| Схема | Влево | Вверх | Вниз | Вправо |
|-------|-------|------|------|--------|
| WASD  | A | W | S | D |
| DFJK  | D | F | J | K |

Также плитку можно двигать кликом мыши: если рядом с ней пустая клетка, она сдвинется на неё. Есть опция инвертирования управления.

## Возможности

- размер поля от 2×2 до 10×10 (меню «Настройки → Размер поля»)
- таймер и счётчик ходов
- лучшее время для каждого размера поля сохраняется в `best_time.json` (вместе с начальной позицией и числом ходов)
- настройка размеров окна
- выбор цветов фона и плиток, сохранение между запусками (`settings.json`), сброс к умолчаниям
- кнопка «Новая игра» в меню «Игра»
- обработка ошибок: исключения в обработчиках показывают окно с сообщением, программа продолжает работу

## Структура проекта

- `main.py` — точка входа
- `board.py` — логика поля: перемешивание, проверка решаемости, ходы
- `app.py` — графический интерфейс, таймер, настройки
- `storage.py` — сохранение рекордов и настроек в JSON
